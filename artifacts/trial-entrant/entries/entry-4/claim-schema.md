# Uniform bounded claim schema v1

Six slots, each `(active: bool, key: bytes32, row_point: F192[20], column_point: F192[20], matrix_values: F192[3])`. F192 is the existing F64 degree-three extension, serialized as three little-endian u64 limbs. A wire key occupies two 128-bit field scalars. Public statement: kind (0 wallet / 1 aggregate), digest bytes32, then all six slots in fixed order, including zero inactive slots. Total 279 field scalars / 6696 native bytes, before certificate serialization. Wallet digest packs the application's existing four-word output; wallet inherited slots are constrained zero.

Each merge fully verifies both children in the same public envelope: row_log=20, column_log=20, block_log=14, public_len=280 including constant one, public_log=9, port_start=16384, q_offset=4194304, stack_log=23, committed_words=8388608. Keys are runtime inputs. Child digest authenticates key, public length and all fields. Ordered node digest binds domain, six dimension pairs and ordered child digests. A child contributes six inherited claims and six copies of its fresh matrix claim, exactly one enabled by constrained one-hot routing. Canonical inactive inherited fields are zero. Same-slot identities agree; different active slots must differ, proved by inverse advice on a differing limb.

Fold transcript: first bind ordered digest and both fresh claims (key, dimensions, row/column points, three evaluations) under r1cs-deferred-matrix-fold-v1; append tree-digest-bound-slots-v3, claim count and every active selector byte. Only then sample theta. Combine A+theta*B+theta^2*C with per-input powers theta^(3i); row sumcheck has 20 rounds, column sumcheck 20; bind each slot's three terminal evaluations in slot order. Inactive outputs have zero evaluations/key/points. Root checks expected digest, complete outer proof, all active generator matrix evaluations, and its fresh own aggregate-matrix claim. The aggregate identity may be inherited and is settled once there plus its fresh evaluation (two distinct points), not omitted.

Intended invariant: with authenticated canonical generators and deterministic derived application keys, an accepted root implies every covered wallet predicate, every inherited matrix claim and every merge-circuit claim is valid, subject to the proof system's soundness/composition assumptions. Current prototype uses a trusted supplied registry; standalone authentication and security calculation remain missing. This entry proves single-key structural reuse and three real applications, not full eligibility.
