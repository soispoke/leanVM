# Baseline deferred schema
Each DeferredClaim is (app_key:32 bytes, row_point:F192[r], col_point:F192[c], matrix_values:F192[3] for A,B,C). F192 serializes three u64 limbs. Four slots have (r,c)=(16,16),(12,12),(20,20),(20,20); each includes active bit. Inactive data is zero. Public node statement is kind, ordered child digest, four slots. Fold binds digest, claims and active flags before sampling theta; row sumcheck then column sumcheck binds inherited and fresh claims with challenge powers. Child proofs are fully replayed. Fresh first/node wrapper claims route to slots 2/3. Duplicate active identities are prohibited across slots. Root checks expected ordered digest, schema, proof, every active generator settlement, and fresh own wrapper settlement. Intended invariant: accepted root implies validity of every covered leaf, inherited claim and wrapper claim, conditional on authenticated generators, protocol soundness and bounded composition. Current code uses trusted registry, not standalone canonical-generator authentication. See tree.rs, fold.rs, deferred.rs and first.rs.
